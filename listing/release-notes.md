# 更新說明（市集發佈時貼進備註欄；只寫玩家看得到的變化）

## 1.0（第一版）

- 序章：聖樹的蛋、王座廳、育嬰室破殼，三個選擇；幫寵物取名字。
- 育嬰室：點心籃（草莓布丁、蜂蜜鬆餅）、玩具箱（騎木馬比劍、辦小茶會）、王室日誌（看狀態、重看序章、重新領養）。
- 黃金便便：撿起來換王室金幣。
- 關掉再開會接著養，不用存檔；離開時間會算進去，肚子會餓、便便會變多，離開太久寵物會鬧脾氣。
- 分化：照陪玩的方式，長大後變成小王子或小公主；王室日誌看得到目前比較像哪一邊。
- 作品聯動：在《仙泉．香布纏》《咒泉．三結義》拿到過的道具，登入後會送到禮物箱；穿衣鏡有六套造型（方天畫戟・百花、方天畫戟・黑金、雙股劍、青龍偃月刀、丈八蛇矛、冷梅帕）。

## 1.0.1

- 育嬰室南邊欄杆：兩端盆栽的葉子和欄柱的金頂原本被切掉一截，補完整；走到欄杆後面會被欄杆擋住。
- 欄杆外面那一排不能再走進去。
- 暫停選單的寵物立繪改成一隻大圖（原本四隻排成一排）。

## 1.1

- 競技場成年禮：分化後再陪牠一陣子，國王的使者會送來邀請，從育嬰室門口出發。小王子表演比劍、小公主辦茶會，兩邊各一張新插畫。
- 王室日誌在辦完成年禮後會寫上新的一句。
- 王城中央廣場：辦完成年禮後，可以從育嬰室門口去廣場散步。廣場開放多人連線，看得到其他玩家的小王子、小公主和他們的造型，可以聊天、送表情。
