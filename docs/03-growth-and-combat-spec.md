# 03. 成長數值與戰鬥技能系統詳細規格

本文件定義《王子姬》的數值計算公式、進化判定矩陣、對戰技能庫與裝備道具。

## 分化（拍板版，2026-10-09）

作者決定分化放在**成長型態**、由**照顧的方式**決定（下面的四維矩陣是最初企劃，原文保留；現在實作的是這一節的簡化版）。

- **傾向**：玩具箱有兩種遊戲，「騎木馬比劍」傾向 +1（小王子）、「辦小茶會」傾向 −1（小公主），兩種一樣加親密度 8、飢餓 10。餵食和寫日誌不影響傾向（每個人都要餵，算進去會讓大家都偏同一邊）。
- **看得到在往哪邊走**：王室日誌多一句。傾向 ≥ 2 寫「比較像一位小王子」、≤ −2 寫「比較像一位小公主」，中間寫「還看不出來」。
- **預告**：親密度到 260，寵物冒一句「身體好像熱熱的」，日誌旁白說牠好像快要長大了（只說一次）。
- **分化**：親密度到 300（約陪玩 30 次）時發光變身。傾向正的變小王子、負的變小公主；打平照最後一次玩的遊戲；一次都沒玩過就先不變，等第一次玩。
- **之後**：穿衣鏡的「平常」換成分化後的樣子；聯動造型兩種共用，照樣穿得上。重新領養會一起還原。
- **畫面**：小王子＝同一頂小金冠加高一點、深藍天鵝絨短披風、金扣；小公主＝小金后冠（粉色愛心寶石）、側邊粉色緞帶、底部粉色蕾絲裙邊。身體大小跟平常那隻一樣。
- **天數（2026-10-10 加，#6）**：除了親密度，還要養到第 3 天（`GROW_DAYS`）才會預告與分化，第 5 天（`ADULT_DAYS`）才會收到成年禮邀請。領養那天是第 1 天，過本機午夜算一天；更新前就領養的玩家從更新那天算起。親密度夠了、天數還沒到時，日誌寫「再陪牠過幾天看看」（成年禮那段寫「要等牠再大一點」）。日誌第一句多了「來到王宮的第 N 天」。
- 變數都跨週目保留：`lean`、`last_play`、`form`、`grow_hint`、`born_at`。門檻在 `build.py` 的 `GROW_AT`、`GROW_HINT`、`LEAN_SHOW`、`GROW_DAYS`、`ADULT_DAYS`。

## 一、 四維人格數值體系

### 1. 數值定義與上限
所有四維數值範圍為 `0 ~ 100`：

- **尊貴度 (Pride)**：`0 ~ 100`（初始 10）
  - 戰鬥換算：`暴擊率 = 5% + (Pride * 0.4%)`（最高 45% 暴擊）。
  - 特殊被動：Pride ≥ 70 時，戰鬥開場自帶「王家氣場護盾」，抵擋前 2 次傷害。
- **嬌貴度 (Spoiled)**：`0 ~ 100`（初始 10）
  - 戰鬥換算：`技能冷卻縮減 (CDR) = Spoiled * 0.3%`（最高 30% CDR）。
  - 特殊被動：Spoiled ≥ 70 時，戰鬥中所有補血與增益道具效果提升 50%。
- **武力/謀略 (Might / Wit)**：`0 ~ 100`（初始 10）
  - 戰鬥換算：直接增加基礎攻擊力 `Attack = Base + (Might * 2.5)`。
  - 特殊被動：Might ≥ 80 解鎖「破甲重擊」；若走 Wit 路線則轉化為「混亂計謀」。
- **社交魅力 (Charm)**：`0 ~ 100`（初始 10）
  - 戰鬥換算：提高敵方命中下降率 `Dodge = Charm * 0.25%`（最高 25% 迴避）。
  - 特殊被動：Charm ≥ 75 時，有機率讓對手陷入「被美貌震懾（眩暈 1 回合）」。

### 3. 日常電子雞飲食與照料道具
1. **日常飲食類**：
   - **皇家特調初乳**：清空飢餓值，幼兒期成長速度 +20%。
   - **松露草莓蛋糕**：嬌貴度 +5，魅力 +3，心情立即轉為高興。
   - **勇者烤黑牛排**：武力 +5，尊貴度 +2，稍微降低撒嬌傾向。
2. **清潔與特殊素材**：
   - **黃金便便 (Golden Poop)**：日常排泄產物。在商店可賣 200 王室金幣，亦可用作「天降黃金炸彈」彈藥。
   - **皇家毛巾與肥皂**：沐浴專用，消除疲勞並預防生病。
3. **基因與聯姻道具**：
   - **王室婚約詔書 (Marriage Decree)**：成年後在大教堂生成一串包含自身四維密碼的字串。
   - **神聖受洗盆 (Holy Font)**：輸入對方的密令後，舉行結合儀式，獲得「二代目之蛋」。
